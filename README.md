### Task 2: Predictive Modeling Using Machine Learning

**Status:** Completed ✅

#### Project Overview

Built a House Price Prediction model using Linear Regression and the Ames Housing Dataset. The model predicts residential property prices based on multiple housing features.

#### Features Used

* GrLivArea
* BedroomAbvGr
* FullBath
* GarageCars
* GarageArea
* OverallQual
* YearBuilt
* TotalBsmtSF

#### Machine Learning Workflow

* Data preprocessing
* Feature selection
* Train-Test Split
* Linear Regression Model Training
* Model Evaluation
* Future Price Prediction
* Model Saving using Pickle

#### Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* Mean Absolute Percentage Error (MAPE)
* R² Score

### Task 3: Exploratory Data Analysis (EDA)

**Status:** Completed ✅

#### Project Overview

Performed Exploratory Data Analysis on the Netflix Movies and TV Shows dataset to identify trends, patterns, and insights from Netflix's global content library.

#### Key Activities

* Data Cleaning
* Missing Value Analysis
* Statistical Analysis
* Trend Analysis
* Correlation Analysis
* Business Insight Generation
* Data Visualization

#### Visualizations Created

* Movies vs TV Shows Distribution
* Top 10 Content Producing Countries
* Netflix Ratings Distribution
* Content Release Trend
* Content Added Per Year
* Top 10 Directors on Netflix
* Correlation Heatmap

#### Key Insights

* Movies dominate Netflix content.
* United States is the leading content-producing country.
* TV-MA is the most common content rating.
* Netflix experienced rapid growth after 2015.
* Content additions peaked during 2019–2020.
