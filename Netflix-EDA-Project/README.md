# Netflix Movies and TV Shows - Exploratory Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset. The objective is to identify trends, patterns, and insights from Netflix's content library using Python and data visualization techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.

## Project Tasks

* Data Cleaning
* Missing Value Analysis
* Statistical Summary
* Data Visualization
* Trend Analysis
* Correlation Analysis

## Visualizations

1. Movies vs TV Shows Distribution
2. Top 10 Content Producing Countries
3. Netflix Ratings Distribution
4. Content Release Trend
5. Content Added Per Year
6. Top 10 Directors on Netflix
7. Correlation Heatmap

## Key Insights

* Movies dominate Netflix content compared to TV Shows.
* United States contributes the highest number of titles.
* India is among the top content-producing countries.
* TV-MA is the most common content rating.
* Netflix experienced significant growth after 2015.
* Content additions peaked around 2019–2020.
* Netflix rapidly expanded its global content library.
* A small group of directors contribute multiple titles.
